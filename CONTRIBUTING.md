## Code of Conduct

All contributors must follow the [OSAIA Code of Conduct](https://github.com/OpenSecureAIAlliance/governance/blob/main/CODE_OF_CONDUCT.md). Violations can be reported to [conduct@secureaialliance.org](mailto:conduct@secureaialliance.org).

---

## Ways to Contribute

- **Attend meetings** — all meetings are open; see the [OSAIA Community Calendar](https://secureaialliance.org/calendar)
- **Join the Working Group** — add yourself to the membership roster via a PR to [MEMBERS.md](./MEMBERS.md)
- **File issues** — inaccuracies, gaps, or ideas via [GitHub Issues](../../issues)
- **Submit pull requests** — improvements to any document in this repository
- **Review open PRs** — feedback is always valuable

---

## Joining the Working Group

Any OSAIA member may join. To become a named member:

1. Open a PR adding your name and organization to [MEMBERS.md](./MEMBERS.md)
2. Ensure your organization is an OSAIA member (see [secureaialliance.org/membership](https://secureaialliance.org/membership))

Each member organization has one vote in Working Group decisions. See the [OSAIA WG Formation and Governance Policy](https://github.com/OpenSecureAIAlliance/governance/blob/main/process/wg-formation.md) for full details.

---

## Submitting Pull Requests

1. Fork this repository and create a branch:
   ```bash
   git checkout -b docs/your-change-description
   ```
2. Make your changes and write a clear commit message
3. Open a Pull Request against `main`
4. At least one Working Group member must approve before merging

---

## Reporting Security Issues

See [SECURITY.md](./SECURITY.md) — do not open a public GitHub issue for security vulnerabilities.

---

## Style Guide

- Plain, direct Markdown
- Sentence case headings
- Spell out acronyms on first use
- Diagrams in [Mermaid](https://mermaid.js.org/) where possible
